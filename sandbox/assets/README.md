# 한글 폰트

NanumGothic-Regular.ttf는 [Google Fonts의 나눔고딕](https://github.com/google/fonts/tree/main/ofl/nanumgothic)에서 가져온 원본이다. NHN의 저작권과 SIL Open Font License 1.1은 OFL.txt에 보존한다. 폰트를 수정하지 않았다.

Sandbox와 Windows UI 테스트를 빌드하면 실행 파일 옆 assets 폴더로 폰트와 라이선스를 복사한다. 배포할 때 실행 파일과 assets 폴더를 함께 제공한다. 실행 시 작업 디렉터리와 무관하게 이 위치에서 폰트를 읽는다.
