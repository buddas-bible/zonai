# Sandbox

화면의 버튼·설명·오브젝트·물리 정보는 한글로 표시한다. 빌드 시 나눔고딕과 라이선스를 실행 파일 옆 `assets` 폴더로 복사하므로 배포할 때 함께 제공한다. 내부 UI ID는 유지하고 단위·키 이름은 그대로 표시한다. ImGui가 생성하는 일부 공통 메뉴도 번역하지만 개발용 Metrics/Debugger 전체를 번역한 것은 아니다.

Windows용 Win32 / Direct3D 11 / Dear ImGui visual playground다. 빌드와 실행은 [루트 문서](../README.md)를 따른다. 물리 library가 Sandbox나 ImGui에 의존하지 않는다.

데모 목록에서 **강체 실험**, **거리 조인트 진자**, **회전축과 막대**, **서스펜션과 바퀴**, **모터 자동차**를 선택한다. 전환/Reset은 현재 데모의 World·선택·설정·입력을 새로 만들고 Pause와 초기 camera로 돌아간다. Sub-steps와 공통 충돌 매트릭스는 공통 설정으로 유지한다.

Inspector는 물리량·재질·충돌 마스크·수면/CCD·센서로 나뉜다. 소속 레이어는 체크 목록으로 편집하며 개별 마스크/그룹은 고급 설정을 펼쳐 편집한다. 공통 충돌 설정에서는 필요한 레이어를 최대 8개씩 표시하고 대칭 관계를 한 번만 편집한다. 숨기는 것은 충돌 규칙을 바꾸지 않는다. 월드·마우스 조인트·물리 정보 표시 설정도 필요할 때 펼친다. [설정의 범위와 우선순위](../docs/sandbox-inspector.md)를 따른다.

- Play/Pause, Step, Reset으로 simulation을 제어한다. 물리는 1/60초 fixed step, 한 frame 최대 8 step이며 긴 frame 뒤 남은 누적 시간은 버린다. Sub-steps는 World solver의 내부 반복 단위를 설정한다.
- Object Inspector에서 pose, velocity, damping, sleep/CCD와 shape material/filter를 편집한다. Playground의 Impulse Test는 중심/중심 밖 impulse와 angular impulse를 비교한다.
- Debug Draw에서 shape/fat AABB, contact separation/impulse, COM/velocity, body type별 tree와 node label을 표시한다.
- Canvas 위 mouse wheel로 cursor 기준 zoom, 가운데 버튼 drag로 pan한다. Reset Camera로 선택한 데모의 초기 view를 복원한다.

| 데모 | 장면 | Canvas 입력 |
| --- | --- | --- |
| Playground | static 바닥/ramp, dynamic circle/box/capsule, kinematic platform | A/D 유지: circle에 힘, Space: jump, S: box 회전, 왼쪽 drag: Dynamic solid 잡기, 오른쪽 클릭: cursor 방향 impulse |
| Distance Pendulum | static anchor와 dynamic circle의 고정 거리 Joint | A/D 유지: 진자에 힘, Space: 옆으로 impulse, 왼쪽 drag: Dynamic solid 잡기, 오른쪽 클릭: cursor 방향 impulse |
| 회전축과 막대 | static 축과 dynamic 막대의 Revolute Joint | A/D: 수평 힘, Space: 위로 impulse, S: 회전, Mouse drag·cursor impulse. 접힌 각도 제한/모터 설정 |
| 서스펜션과 바퀴 | static 지지대와 dynamic 원의 Wheel Joint | A/D: 축 옆 힘, Space: 위로 impulse, S: 회전, Mouse drag·cursor impulse. 접힌 주파수/감쇠·이동 제한·회전 모터 설정, 방향 전환·제동 |
| 모터 자동차 | 차체와 두 구동 바퀴·평지·낮은 경사면 | A/D 유지: 주행, 스페이스 유지: 제동, 키 해제: 자유 주행. 접힌 모터/서스펜션 설정 |

입력은 Canvas 위에서만 전달한다. UI 편집·창 focus 상실·가운데 drag 중에는 유지 입력을 취소한다. 왼쪽 drag는 Mouse Joint이며 오른쪽 클릭은 impulse 실험이다. Mouse Joint 설정에서 Hertz/damping/max force를 바꾸고 주황색 anchor/target과 point error/force를 관찰한다. Paused 상태는 다음 Step/Play까지 pose를 진행하지 않는다. 취소 뒤 재시작에는 새 press가 필요하다. [제약의 수학과 수명](../docs/mouse-joint.md)을 따른다.

`main.cpp`는 platform 자원·공통 UI·camera·입력·fixed-step loop를 연결한다. `demo`/`demoSession`은 작은 데모 계약과 전환/시간 진행을 맡는다. `rigidBodyDemo`가 World와 장면/물리 입력을 소유하고 `rigidBodyDemoUi`가 Inspector/설정/표시를 맡는다. `debugCamera`는 좌표 변환과 camera 조작, `debugDraw`는 geometry/tree 표시를 담당한다. 새 데모를 추가하는 방법과 장기 학습 방향은 [데모 문서](../docs/sandbox-demos.md)에 있다.

화면의 contact 수집은 `UpdateCollisions`를 호출하므로 순수 조회만 하는 UI는 아니다. 자동 테스트의 대체나 성능 benchmark로 사용하지 않는다. ImGui headless frame 검사는 있지만 실제 창/GPU/OS 입력과 시각 검증·device-loss 복구를 보장하지 않는다.

## Distance Joint 진자

보라색 선과 두 anchor 점은 Distance Joint다. 처음에는 rigid이며 Controls에서 Distance spring을 켜고 Hertz/damping을 조절한다. ‘진자 축 방향으로 밀기’로 축 방향 진동을 시작하고 ‘진자 옆으로 밀기’로 옆으로 민다. 목표/현재 거리, 늘어난 길이와 signed 축 방향 힘을 관찰한다. Limit을 켜면 초록색 min/빨간색 max와 허용 구간을 표시한다. Spring on/0 Hz는 스프링 힘만 끄며 limit과 motor는 유지한다. Rigid는 range와 motor를 무시하고 같은 min/max는 Target의 rigid로 돌아간다. 부드러운 경계이므로 하중 아래 작은 오차가 남는다. Reset은 rigid/2 Hz/감쇠 0.7, limit off/min 1.5 m/max 2.5 m로 돌아간다. [Spring](../docs/distance-spring.md), [limit](../docs/distance-limit.md), [motor](../docs/distance-motor.md)의 수학·조작·검증을 따른다. Body local anchor는 원점 기준이며 solver에서는 COM 기준 lever arm으로 바뀐다. CCD가 이동을 자른 frame에서는 거리 오차가 일시적으로 커질 수 있다.

## 모터 자동차

연결 장치 카테고리에서 선택한다. 캔버스 위 A/D로 주행하고 스페이스를 유지하여 제동한다. 키 해제는 모터 off의 자유 주행이다. 모터·서스펜션·바퀴 반력 설정은 기본 접혀 있으며 양쪽 바퀴를 함께 조절한다. 차체 속도와 타이어 마찰, 경사면 변위를 비교하고 가운데 드래그로 경로를 따라간다. UI 편집/Pause는 입력을 취소하며 Reset은 초기 장면과 8 rad/s·바퀴당 5 N·m 설정으로 돌아간다. [조작·수학·검증 범위](../docs/motor-car.md)를 따른다.

## Wheel Joint 서스펜션

‘서스펜션과 바퀴’의 접힌 스프링 설정에서 3 Hz/감쇠 0.7을 바꾸고 축 변위·수직 오차·힘·바퀴 각속도를 비교한다. 스프링 off/0 Hz는 스프링 힘만 끄며 수직 제약과 자유 회전은 유지한다. 접힌 ‘이동 범위 제한’에서 준비된 -0.5~0.5 m를 켜거나 편집하면 스프링을 꺼도 경계를 유지한다. 초록은 최소, 빨강은 최대, 회색은 허용 구간이다. 제한도 끄면 중력으로 떨어진다. 청록색 점은 중립점, 화살표는 축의 양의 방향, 보라색은 바퀴와 회전 방향이다. [기본 좌표계](../docs/wheel-joint.md)와 [이동 제한의 수학·검증](../docs/wheel-limit.md)을 따른다. 접힌 [회전 모터](../docs/wheel-motor.md)는 off/목표 3 rad/s/최대 1 N·m로 시작한다. 펼쳐 사용 여부·속도·토크를 조절하고 방향 전환·제동을 비교한다. 속도 0은 제동하며 토크 0은 힘을 끈다. 후속 [자동차](../docs/motor-car.md)는 차체·두 바퀴·마찰·경사면을 조합한다.

## 강체 비교 시험

기존 강체 카테고리에서 다음 장면을 선택한다. 물체와 바닥은 기존 오브젝트 인스펙터로 편집한다.

| 장면 | 관찰할 동작 |
| --- | --- |
| 충돌 비교 | 중력 없이 마주 오는 원·상자·캡슐 쌍. 밀도·반발·감쇠를 바꿔 충돌 후 운동을 비교한다. |
| 마찰 비교 | 같은 경사면과 상자 3개. 상자의 초기 마찰은 0 / 0.1 / 0.8, 경사면은 1이다. 양쪽 계수의 기하평균이 접촉 마찰이다. |
| 반발 비교 | 같은 높이의 원 3개. 초기 반발은 0 / 0.5 / 1, 바닥은 0이다. 양쪽 중 큰 계수가 접촉 반발이다. |
| 상자 쌓기 | 상자 8개의 낙하·쌓임·수면. 마찰·밀도·감쇠·수면 설정을 편집하거나 드래그로 건드린다. |

**시험 복귀 (편집값 유지)**는 기존 물체 handle과 선택을 유지하며 모든 물체의 위치·회전·출발 속도를 장면의 초기값으로 복원한다. 드래그와 유지 입력, 누적 힘·토크를 해제하고 물체를 깨운 뒤 접촉 정보를 갱신한다. 재질·밀도·질량·감쇠·중력·충돌 필터·수면·CCD 설정과 재생/정지 상태는 유지한다. 인스펙터에서 편집한 위치·회전·속도는 복귀 시 초기값으로 돌아간다. 정지 → 시험 복귀 → 1프레임 순서로 반복 비교할 수 있다.

상단 **초기화**는 장면을 새로 만들어 장면의 편집값도 기본 상태로 되돌리고 정지한다. 공통 충돌 매트릭스와 하위 단계 수는 기존 정책대로 유지한다. 물체 이름의 계수는 초기값이며 현재 값은 인스펙터에서 확인한다. 기존 인스펙터에 실행 중 회전 고정 편집 기능은 없으며 이번 데모에서도 추가하지 않는다.

## 고속 충돌 CCD 비교

강체 카테고리에서 선택한다. 중력 없는 월드에서 반지름 0.1m의 원이 x=-0.8m에서 100m/s로 출발하며, x=0에 두께 0.1m의 정적 벽이 있다. 처음에는 정지 상태이므로 **시험 복귀 → 1프레임**으로 관찰한다. 월드 설정의 **CCD 검사**를 끄면 원이 벽을 통과하고, 켠 뒤 같은 조건으로 복귀하면 벽 앞에서 이동이 잘리는 것을 비교할 수 있다.

기존 인스펙터에서 원·벽의 재질·밀도·감쇠·중력·안전 계수·Bullet 등을 편집할 수 있다. 시험 복귀는 편집값과 월드 CCD 설정·선택·재생 상태를 유지하고 기본 위치·100m/s 출발 속도로 복원한다. 전체 초기화는 새 장면과 기본 CCD 켜짐으로 돌아간다. Bullet을 끄는 것은 CCD 전체를 끄는 것과 다르다. 일반 고속 물체도 정적 벽을 검사하며 Bullet은 동적·키네마틱 물체까지 검사 대상을 확장한다.

## 충돌 필터 비교

강체 카테고리에서 선택한다. 중력 없는 월드에서 동일한 원 두 쌍이 위·아래로 나뉘어 서로 마주 온다. 각 원의 반지름은 0.35m, 출발 위치는 x=±2m와 y=±1.5m, 속도는 2m/s, 반발계수는 1이다. 처음에는 위쪽이 충돌해 되돌아가고, 아래쪽은 A의 마스크가 B의 레이어 02를 제외해 통과한다.

인스펙터에서 **아래 A → 충돌 마스크 → 개별 추가 제한 → 충돌 대상 레이어 02**를 켠 뒤 시험 복귀하면 아래쪽도 충돌한다. 반대로 어느 한쪽이라도 상대 레이어를 제외하면 통과한다. 소속 레이어·그룹·재질 등은 기존 인스펙터에서 편집한다. 물체 이름의 레이어는 초기값이며 현재 설정은 인스펙터에서 확인한다. 공통 충돌 설정은 모든 쌍에 함께 적용되고 양수 그룹도 공통 금지를 우회하지 않는다.

**시험 복귀 (편집값 유지)**는 모든 원의 초기 위치·회전·속도를 복원하고 편집값·선택·공통 충돌 설정·재생 상태를 유지한다. 정지 → 시험 복귀 → 재생 또는 1프레임으로 같은 출발 조건을 비교한다. 상단 초기화는 물체 편집값을 기본값으로 되돌리고 정지하지만 공통 충돌 설정과 하위 단계 수는 유지한다.

## 센서·일반 벽 비교

강체 카테고리에서 선택한다. 중력 없는 월드에서 위쪽은 일반 벽, 아래쪽은 보라색 센서 영역이다. 두 영역은 x=0, y=±1.5m에 반폭 0.75m·반높이 0.6m로 배치되며, 반지름 0.35m인 원이 각각 x=-3m에서 2m/s로 출발한다. 위 원은 벽에 막히고 아래 원은 속도를 유지하며 센서를 통과한다. 반복 시험 영역과 센서 인스펙터에서 마지막 진행 단계의 겹침 수를 확인한다.

센서와 아래 원은 처음에 센서 이벤트가 켜져 있다. 어느 한쪽의 **센서 → 센서 이벤트**를 끄면 다음 진행 단계부터 감지가 중단되지만 센서는 계속 통과할 수 있다. 다시 켜면 이미 안에 있는 원도 감지한다. 충돌 마스크와 공통 충돌 설정도 센서 감지에 적용된다. 재질·밀도·감쇠 등은 기존 인스펙터에서 편집한다.

**시험 복귀 (편집값 유지)**는 위치·회전·출발 속도를 복원하고 드래그·유지 입력·누적 힘을 해제한다. 센서 이벤트·마스크·물성·중력·선택·공통 설정·재생 상태는 유지한다. 시간을 진행하지 않고 복원된 위치의 겹침을 다시 계산하므로 이전 시험의 겹침 수가 남지 않는다. 상단 초기화는 새 장면과 기본 이벤트 설정으로 돌아가며 정지한다. 공통 충돌 설정과 하위 단계 수는 기존 정책대로 유지한다.

## 수면·깨우기 비교

강체 카테고리에서 선택한다. 같은 바닥 위에 동일한 상자 두 개를 x=±2m, y=1.5m에 배치한다. 바닥의 윗면은 y=0이고 상자는 한 변이 1m이며 바닥·상자의 마찰은 0.6이다. 처음에는 왼쪽만 자동 수면을 허용한다. 재생해 안정된 뒤 왼쪽은 잠들고 오른쪽은 깨어 있는 상태를 기존 도형 색상과 반복 시험 영역의 현재 상태로 비교한다. 이름의 수면 허용 여부는 초기값이다.

## 동적·키네마틱 충돌 비교

정지 → **시험 복귀 (편집값 유지)** → 재생·1프레임으로 비교한다. 위쪽은 같은 질량의 비탄성 충돌 후 이동 상자와 표적이 약 1m/s로 움직인다. 아래쪽 키네마틱 상자는 지정 속도 2m/s를 유지하며 표적을 더 멀리 민다. 인스펙터의 **물리량 → 밀도**를 바꾸면 동적 쌍의 질량비와 충돌 결과가 달라진다. 키네마틱 모양의 밀도를 바꿔도 물리 계산에 사용하는 질량은 0이며 충돌 반작용으로 감속하지 않는다. 키네마틱에도 선속도는 기존 인스펙터에서 직접 지정할 수 있다.

**충돌 재질 → 반발 계수**를 편집하면 튕겨 나가는 반응을 비교할 수 있다. 표시된 초기 질량·속도에 대한 설명은 기본 설정 기준이며 편집한 중력·감쇠·반발·마스크 등에 따라 결과가 달라질 수 있다. 표적 거리는 초기 위치와 현재 위치 사이 거리다.

시험 복귀는 드래그·유지 입력·누적 힘을 해제하고 초기 위치·회전·이동 상자 2m/s·표적 정지 속도를 복원한다. 밀도·물성·감쇠·수면·중력·선택·공통 설정·재생 상태와 물체 유형은 유지한다. 상단 초기화는 새 장면의 기본 설정으로 돌아가며 정지한다. 공통 충돌 설정과 하위 단계 수는 기존 정책대로 유지한다.

## 복합 물체·질량중심 비교

강체 카테고리에서 선택한다. 반지름 0.5m 원 두 개를 물체 기준 x=-0.75·0.75m에 연결한 동적 강체 두 개를 x=-3·3m에 배치한다. 각 원은 독립 강체가 아닌 같은 강체의 모양이며, 회색 연결선이 묶임을 표시한다. 초기 밀도는 대칭 강체 2·2, 비대칭 강체 1·3이다. 전체 질량은 모두 πkg이지만 물체 기준 질량중심은 각각 (0,0)·(0.375,0)m이다. 처음에는 중력·감쇠·자동 수면을 끈다.

**같은 원점 충격량 적용**은 각 강체의 현재 물체 원점에 위쪽 2N·s를 한 번씩 추가한다. 모양이 두 개여도 강체마다 한 번만 적용한다. 주황색 점·화살표는 실제 원점과 충격량 방향, 분홍색 점은 질량중심이며 기존 질량 중심 표시 설정을 따른다. 초기 자세에서는 두 강체의 질량중심 선속도가 모두 2/πm/s씩 증가하지만 비대칭 강체만 시계 방향으로 회전한다. 반복 적용은 현재 속도에 누적되며, 회전한 뒤에는 원점과 질량중심의 방향 관계에 따라 회전 반응이 달라진다. 선속도는 질량중심의 속도다.

오브젝트 인스펙터에서 각 원을 선택하고 **물리량 → 밀도**를 바꾸면 강체 전체의 질량·회전 관성·질량중심이 즉시 갱신된다. 비대칭 강체의 밀도를 3·1로 뒤집고 시험 복귀 후 적용하면 같은 전체 질량에서 회전 방향이 반대로 바뀐다. 두 원의 상대 위치는 회전 중에도 고정된다. 현재 강체 전체의 질량·회전 관성·물체 기준 질량중심·속력·각속도를 반복 시험 영역에 표시한다. 대칭·비대칭 이름과 밀도 설명은 초기 배분 기준이다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘을 해제하고 초기 물체 원점·회전·정지 속도를 복원한다. 개별 원의 밀도와 그로부터 계산한 질량중심·물성·감쇠·수면·중력·선택·공통 설정·재생 상태는 유지한다. 자동으로 충격량을 다시 주지 않는다. 상단 초기화는 새 장면의 기본 밀도 배분으로 돌아가며 정지한다. 공통 충돌 설정과 하위 단계 수는 기존 정책대로 유지한다.

## 고속 회전 제한 비교

강체 카테고리에서 선택한다. 같은 2×0.25m 동적 막대 두 개를 x=-2.5·2.5m에 배치하고 각속도 120rad/s·선속도 0으로 출발한다. 초기 빠른 회전 허용은 A 꺼짐·B 켜짐이며 중력·감쇠·자동 수면을 끈다. 충돌 없이 각속도 제한 자체를 비교한다.

정지 → **시험 복귀 (편집값 유지)** → 1프레임으로 비교한다. 빠른 회전을 허용하지 않으면 전체 진행 간격당 회전을 45도 이하로 제한한다. 각속도 상한은 π/(4·진행 간격)rad/s이며, 기본 1/60초에서는 A가 약 47.12rad/s로 제한되고 B는 120rad/s를 유지한다. 내부 분할 수를 늘려도 기준은 전체 진행 간격이다. 최근 양의 진행 간격과 그 간격에서의 비허용 각속도 제한, 각 막대의 현재 허용 여부·각속도·속력을 표시한다. 진행 전이나 시험 복귀 직후에는 간격·제한을 아직 진행하지 않음으로 표시하며, 시간 0의 갱신은 마지막 양의 간격을 지우지 않는다.

기존 인스펙터의 **Sleep과 CCD → 빠른 회전 허용**을 바꾸고 시험 복귀 후 다시 진행하면 결과가 바뀐다. 허용을 켜는 것만으로 이미 줄어든 각속도가 복원되지는 않는다. 시험 복귀는 두 막대의 각속도를 다시 120rad/s로 맞춘다. 물체 이름은 초기 설정 기준이며 현재 상태는 표시값을 확인한다. 선속도·밀도·감쇠 등도 기존 인스펙터에서 편집할 수 있다. 회전 제한은 선속도를 바꾸지 않는다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘을 해제하고 초기 위치·회전·각속도 120rad/s·선속도 0을 복원하며 진행 간격 표시를 초기화한다. 빠른 회전 허용·물성·감쇠·수면·중력·선택·공통 설정·재생 상태는 유지한다. 상단 초기화는 새 장면의 기본 설정으로 돌아가며 정지한다. 공통 충돌 설정과 하위 단계 수는 기존 정책대로 유지한다.

## 최대 선속도 비교

강체 카테고리에서 선택한다. 같은 1m 정사각형 동적 상자 두 개를 x=-2.5·2.5m에 배치하고 같은 대각선 방향 (0.6,0.8)으로 A=2·B=8m/s로 출발한다. 초기 월드 최대 선속도는 4m/s이며 중력·감쇠·자동 수면을 끈다. 초기 각속도는 0이다. 현재 월드 제한값과 각 상자의 선속도 성분·속력·각속도를 표시한다.

정지 → **시험 복귀 (편집값 유지)** → 1프레임으로 비교한다. 제한은 물리 진행 단계에서 위치를 적분하기 전에 적용하며, 처음에는 A가 2m/s를 유지하고 B만 4m/s로 줄어든다. 이동 방향은 바뀌지 않아 선속도는 각각 (1.2,1.6)·(2.4,3.2)m/s가 된다. 최대 선속도는 각속도를 바꾸지 않는다.

기존 **월드 설정 → 최대 선속도**를 8m/s로 높이고 시험 복귀 후 진행하면 두 상자가 초기 2·8m/s를 유지한다. 1m/s로 낮추면 둘 다 같은 방향의 1m/s로 제한된다. 제한값을 높이는 것만으로 이미 줄어든 속도가 복원되지는 않는다. 선속도·각속도·밀도·감쇠 등은 기존 인스펙터에서 편집할 수 있다. 설명과 물체 이름의 속도는 초기 조건 기준이다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘을 해제하고 초기 위치·회전·선속도 2·8m/s·각속도 0을 복원한다. 편집한 월드 최대 선속도·물성·감쇠·수면·중력·선택·공통 설정·재생 상태는 유지한다. 상단 초기화는 새 장면의 최대 선속도 4m/s와 기본 설정으로 돌아가며 정지한다. 공통 충돌 설정과 하위 단계 수는 기존 정책대로 유지한다.

## 마찰 혼합 규칙 비교

강체 카테고리에서 선택한다. y=2·0·-2m에 수평 바닥 세 개를 두고, 같은 0.8m 정사각형 동적 상자를 x=-3m에서 오른쪽 4m/s로 출발시킨다. 바닥의 반너비·반높이는 (6,0.15)m이며 상자 중심은 바닥 중심보다 0.55m 위에 둔다. 월드 중력은 (0,-10)m/s²이고 반발·감쇠·자동 수면을 끈다.

초기 바닥·상자 마찰 조합은 A=(0.25,1), B=(1,0.25), C=(1,0)이다. 혼합 계수는 두 마찰 곱의 제곱근으로 A·B는 모두 0.5, C는 0이다. A·B는 계수를 교환해도 같은 감속을 보이며 멈추고, C는 바닥 위에서 수평 속도를 유지한다. 첫 0.5~1.5초를 비교하면 차이를 관찰하기 쉽다. 바닥은 유한하므로 오래 진행하면 마찰 없는 상자가 끝을 지나 떨어질 수 있다.

반복 시험 영역에 현재 바닥·상자 계수, 그로부터 계산한 혼합 계수와 상자 속력을 표시한다. 오브젝트 인스펙터에서 각 바닥 또는 상자를 선택해 **충돌 재질 → 마찰 계수**를 바꾸고 시험 복귀 후 재시험한다. 어느 한쪽을 0으로 바꿔도 그 쌍의 혼합 마찰이 0이 된다. 기존 밀도·반발·감쇠·중력·수면 등 편집 경로는 그대로 사용하며, 바꾼 다른 설정이나 바닥 끝의 영향이 있으면 기본 비교 결과와 달라질 수 있다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘을 해제하고 바닥·상자의 초기 위치·회전을 복원한다. 상자는 출발 선속도 (4,0)m/s·각속도 0, 바닥은 정지 상태로 돌아간다. 양쪽 마찰을 포함한 물성·밀도·감쇠·수면·중력·선택·공통 설정·재생 상태는 유지한다. 상단 초기화는 원래 세 마찰 조합과 기본 설정으로 돌아가며 정지한다. 공통 충돌 설정과 하위 단계 수는 기존 정책대로 유지한다.

## 반발 혼합 규칙 비교

강체 카테고리에서 선택한다. x=-3·0·3m에 각각 분리된 수평 바닥과 반지름 0.4m 원을 배치한다. 바닥 반너비·반높이는 (1.25,0.15)m이고 윗면 높이는 0m다. 같은 원 세 개가 중심 높이 3m의 정지 상태에서 낙하한다. 월드 중력은 (0,-10)m/s²이며 마찰·감쇠·자동 수면을 끈다.

초기 바닥·원 반발 조합은 A=(0,0.8), B=(0.8,0), C=(0,0)이다. 혼합 계수는 두 반발 중 큰 값이므로 A·B는 모두 0.8, C는 0이다. A·B는 계수를 교환해도 같은 높이로 튀고 C는 바닥에서 튀지 않는다. 한쪽 반발이 0이어도 다른 쪽이 더 크면 그 값이 적용된다. 낮은 충돌 속도에서는 기존 엔진의 반발 억제 정책이 함께 적용된다.

반복 시험 영역에 현재 바닥·원 계수, 그로부터 계산한 혼합 계수, 원의 중심 높이·세로 속도를 표시한다. 오브젝트 인스펙터에서 각 바닥 또는 원을 선택해 **충돌 재질 → 반발 계수**를 바꾸고 시험 복귀 후 재시험한다. A 원과 B 바닥의 계수를 0.4로 낮추면 같은 낮은 반발을 비교할 수 있다. A 바닥을 1로 바꾸면 원의 0.8보다 큰 값이 적용된다. 기존 밀도·마찰·감쇠·중력 등 편집 경로도 그대로 사용한다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘을 해제하고 바닥·원의 초기 위치·회전·정지 속도를 복원한다. 양쪽 반발을 포함한 물성·밀도·감쇠·수면·중력·선택·공통 설정·재생 상태는 유지한다. 상단 초기화는 원래 세 반발 조합과 기본 설정으로 돌아가며 정지한다. 공통 충돌 설정과 하위 단계 수는 기존 정책대로 유지한다.

## 저속 반발 억제 비교

## 정면·편심 충돌 비교

**강체 → 정면·편심 충돌 비교**에서 반지름 0.2m인 같은 원 세 개가 정지한 같은 1m 정사각형 상자를 오른쪽 4m/s로 친다. A는 상자 중심, B는 중심 위 0.25m, C는 중심 아래 0.25m를 향한다. 원·상자의 초기 밀도는 1이고 반발은 1, 중력·마찰·감쇠·자동 수면은 끈다.

정지 → **시험 복귀 (편집값 유지)** → 재생으로 처음 0.75초를 비교한다. A 상자는 중심 충돌로 전진하며 회전하지 않는다. B는 시계 방향, C는 반시계 방향으로 비슷한 크기의 회전을 얻는다. 마찰이 없어도 중심에서 벗어난 충돌의 법선 방향 충격량은 회전을 만든다.

기존 인스펙터의 **물리량 → 밀도**에서 B 또는 C 상자의 밀도를 2로 높이고 시험 복귀하면 해당 상자의 이동·회전 반응이 줄어든다. 다른 두 쌍은 기존 반응을 유지한다. 기존 반발·물성 편집도 사용할 수 있으며 반복 시험 영역에 상자의 현재 질량·가로/세로 속도·각속도를 표시한다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘을 해제하고 원·상자의 초기 위치·회전을 복원한다. 원은 오른쪽 4m/s·각속도 0, 상자는 정지 상태로 돌아간다. 밀도·질량·마찰·반발·감쇠·수면·중력·선택·공통 설정·재생 상태는 유지한다. 상단 초기화는 원래 밀도와 장면의 기본 설정으로 돌아가며 정지한다. 공통 충돌 설정과 하위 단계 수는 기존 정책대로 유지한다.

## 거리 스프링·감쇠 비교

**조인트 → 거리 스프링·감쇠 비교**에서 같은 질량의 원 세 개가 고정점 아래의 거리 스프링에 연결된다. 목표 길이는 1m, 초기 길이는 1.5m로 0.5m 늘린 상태이며 주파수는 모두 2Hz이다. 초기 감쇠비는 A 0, B 0.7, C 2이다. 중력·물체 감쇠·자동 수면은 끄고 거리 제한·모터는 사용하지 않는다.

정지 → **시험 복귀 (편집값 유지)** → 재생으로 진동과 수렴을 비교한다. A는 목표 길이를 넘나드는 진동이 크고, B는 진동이 빠르게 줄며, C는 목표 길이를 넘지 않고 천천히 접근한다. 진동 크기는 수치적 감쇠와 내부 분할 수의 영향도 받으므로 같은 진행 설정에서 비교한다. 보라색 선은 현재 연결, 고정점의 원은 목표 거리이다.

반복 시험 영역에서 각 물체의 **스프링 주파수·감쇠비**를 독립적으로 편집하고 현재 길이·세로 속도를 확인한다. A 감쇠비를 2로 바꾸면 C와 같은 출발 궤적을 보이고, B 주파수를 1Hz로 낮추면 초기 복원이 느려진다. 0Hz는 스프링 힘을 끄므로 기본 무중력 조건에서는 복귀 후 그 자리에 머문다. 기존 오브젝트 인스펙터에서 밀도·물성·감쇠·중력 등을 편집하고 물체를 드래그할 수도 있다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘과 조인트의 누적 충격량을 해제하고 물체의 초기 위치·회전·정지 속도를 복원한다. 조인트 핸들·주파수·감쇠비·물성·밀도·중력·선택·공통 설정·재생 상태는 유지한다. 상단 초기화는 원래 감쇠비·주파수와 기본 장면으로 돌아가며 정지한다. 공통 충돌 설정과 하위 단계 수는 기존 정책대로 유지한다.

## 거리 모터·힘 한도 비교

**조인트 → 거리 모터·힘 한도 비교**에서 같은 반지름 0.2m·밀도 1의 원 세 개가 고정점 아래의 거리 모터에 연결된다. 초기 길이는 1m, 목표 속도는 모두 거리 증가 방향 1m/s이며 힘 한도는 A 0, B 0.05, C 2N이다. 중력·물체 감쇠·자동 수면·거리 제한은 끄고 스프링 모드의 0Hz로 스프링 힘만 제거한다.

정지 → **시험 복귀 (편집값 유지)** → 재생으로 처음 1초를 비교한다. A는 정지하고 B는 천천히 가속하며 C는 빠르게 목표 속도를 따라간다. 힘 한도는 가속 능력을 제한하므로 B도 충분히 오래 진행하면 목표 속도에 도달할 수 있다. 하늘색 선과 점은 현재 연결과 고정점이다.

반복 시험 영역에서 각 모터의 **목표 속도·힘 한도**를 독립적으로 편집하고 현재 길이·축 방향 속도·실제 모터 힘을 확인한다. A 힘 한도를 2N으로 높이면 목표 속도를 따라가고, C 목표를 0.5m/s로 낮추면 그 속도를 따른다. 양수는 거리를 늘리고 음수는 줄인다. 기존 오브젝트 인스펙터의 밀도 편집도 사용할 수 있으며 같은 약한 모터 힘에서 질량이 커지면 가속이 느려진다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘과 조인트의 누적 충격량을 해제하고 초기 위치·회전·정지 속도를 복원한다. 조인트 핸들·목표 속도·힘 한도·물성·밀도·중력·선택·공통 설정·재생 상태는 유지한다. 상단 초기화는 원래 모터 설정과 기본 장면으로 돌아가며 정지한다. 공통 충돌 설정과 하위 단계 수는 기존 정책대로 유지한다.

## 거리 제한·모터 비교

**조인트 → 거리 제한·모터 비교**에서 같은 질량의 원 두 개를 고정점 아래에 연결한다. 초기 길이 1m·목표 속도 1m/s·최대 모터 힘 2N은 같고, A는 거리 제한 꺼짐, B는 0.75~1.5m 제한 켜짐으로 시작한다. 중력·물체 감쇠·자동 수면을 끄고 스프링 모드를 0Hz로 설정해 스프링 힘 없이 모터·제한만 비교한다.

정지 → **시험 복귀 (편집값 유지)** → 재생으로 처음 1초를 비교한다. A는 계속 늘어나고 B는 상한 1.5m에서 멈춘다. 각 물체의 목표 속도를 -1m/s로 바꾸면 B는 하한 0.75m까지 줄어든 뒤 멈춘다. 경계에서 목표 속도의 부호를 바꾸면 반대 방향으로 출발한다. 유한한 모터 힘 때문에 이동 중 방향 전환에는 제동·가속 시간이 필요하다.

각 물체의 **거리 제한 활성화·하한·상한·목표 속도**를 독립적으로 편집하고 현재 길이·축 방향 속도·실제 모터 힘을 확인한다. A 제한을 켜면 상한에서 멈추고, B 제한을 끄면 계속 이동한다. 초록 원은 활성화된 하한, 빨강 원은 상한이다. 하한과 상한이 같으면 기존 엔진 정책에 따라 목표 길이 1m의 고정 거리 제약으로 돌아가며 모터는 작동하지 않는다. 기존 인스펙터의 밀도·재질·감쇠 편집과 왼쪽 드래그도 유지한다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘과 조인트의 누적 충격량을 해제하고 초기 위치·회전·정지 속도를 복원한다. 조인트·물체 handle과 편집한 제한·목표 속도·물성·월드 설정·선택·재생 상태는 유지한다. 상단 초기화는 장면의 기본 설정으로 돌아가며 정지한다.

## 회전 모터·토크 한도 비교

**조인트 → 회전 모터·토크 한도 비교**에서 같은 크기·밀도의 막대 세 개를 고정된 중심 회전축에 연결한다. 막대의 반크기는 (0.5, 0.1)m이고 초기 각속도는 0이다. 목표 각속도는 모두 2rad/s이며 최대 모터 토크는 A 0, B 0.01, C 0.2N·m로 시작한다. 중력·물체 감쇠·자동 수면·각도 제한을 끄고 토크 한도에 따른 정지·가속·속도 추종을 비교한다.

정지 → **시험 복귀 (편집값 유지)** → 재생으로 처음 1초를 비교한다. A는 정지하고 B는 천천히 가속하며 C는 목표 각속도를 빠르게 따라간다. 약한 모터도 충분한 시간이 지나면 목표에 도달할 수 있다. 목표 각속도를 -2rad/s로 바꾸면 감속한 뒤 반대 방향으로 회전하고, 0이면 토크 한도 안에서 제동한다. 토크 한도가 0인 모터는 이미 회전 중인 막대를 멈추지 않는다.

각 물체의 **목표 각속도·토크 한도**를 독립적으로 편집하고 실제 각속도·모터 토크를 확인한다. A 토크를 0.2N·m로 바꾸면 C와 같은 가속을 보이고, C 목표 각속도를 1rad/s로 바꾸면 그 속도로 추종한다. 기존 인스펙터에서 밀도를 높이면 회전 관성이 증가해 같은 토크의 가속이 느려진다. 물성·감쇠 편집과 왼쪽 드래그도 유지한다. 파란 점은 중심 회전축이다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘·토크와 조인트의 누적 충격량을 해제하고 막대의 초기 위치·회전·정지 속도를 복원한다. 물체·조인트 handle과 편집한 목표 각속도·토크 한도·물성·월드 설정·선택·재생 상태는 유지한다. 상단 초기화는 장면 기본 설정으로 돌아가며 정지한다.

## 회전 각도 제한·모터 비교

정지 → **시험 복귀 (편집값 유지)** → 재생으로 처음 1초를 비교한다. A는 계속 회전하고 B는 상한 45°에서 멈춘다. 목표 각속도를 -2rad/s로 바꾸면 B는 하한 -45°까지 회전한 뒤 멈춘다. 경계에서 목표 부호를 바꾸면 반대 방향으로 출발한다. 유한한 토크 한도로 인해 가속·제동에는 시간이 필요하다.

각 물체의 **각도 제한 활성화·하한·상한·목표 각속도**를 독립적으로 편집하고 현재 각도·각속도를 확인한다. A 제한을 켜면 경계에서 멈추고, B 제한을 끄면 계속 회전한다. 각도 편집·표시는 도 단위를 사용한다. 현재 각도는 기준각 0°에 대한 -180°~180° 값이며 회전 횟수를 누적하지 않는다. 하한과 상한이 같으면 기존 엔진 정책에 따라 해당 각도를 유지한다. 파란 점은 중심축, 초록 선은 활성화된 하한, 빨강 선은 상한이다. 기존 인스펙터의 밀도·물성·감쇠 편집과 왼쪽 드래그도 유지한다.

## 서스펜션·하중 비교

**조인트 → 서스펜션·하중 비교**에서 같은 크기·밀도의 바퀴 세 개를 고정 지지대의 수직 Wheel Joint에 연결한다. 초기 축 변위는 0m, 주파수는 A 0.5, B 1, C 2Hz, 감쇠비는 모두 0.7이다. 중력 (0, -9.8)m/s² 아래에서 주파수에 따른 처짐·수렴을 비교한다. 모터·이동 제한·물체 감쇠·자동 수면을 끄고 초기 각속도 2rad/s로 자유 회전한다.

정지 → **시험 복귀 (편집값 유지)** → 재생으로 같은 초기 조건을 비교한다. 낮은 주파수는 더 크게 처지고 천천히 수렴하며 높은 주파수는 더 작은 변위로 빠르게 수렴한다. 축 변위의 음수는 아래 방향이다. 충분히 수렴하면 스프링 반력이 무게를 지지한다. 수직 이동축은 유지하면서 바퀴의 회전은 제한하지 않는다. 청록 화살표는 이동축, 점은 변위 0 기준, 바퀴의 보라색 화살표는 회전 자세를 보여준다.

각 바퀴의 **스프링 주파수·감쇠비**를 독립적으로 편집하고 축 변위·스프링 반력·세로 속도·각속도를 확인한다. A 주파수를 2Hz로 바꾸면 C와 같은 처짐을 보이고, B 감쇠비를 2로 바꾸면 초기 수렴 과정이 달라진다. 0Hz는 스프링 힘만 꺼 무중력 상태로 만드는 대신 중력 아래에서 낙하한다. 기존 인스펙터의 밀도·물성·감쇠 편집과 왼쪽 드래그도 유지한다. 주파수 기반 스프링은 질량에 맞춰 강도를 계산하므로 같은 주파수에서 밀도를 높이면 평형 처짐은 유지되고 필요한 지지 반력은 증가한다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘·토크와 조인트의 누적 충격량을 해제하고 초기 위치·회전·선속도 0·각속도 2rad/s를 복원한다. 물체·조인트 handle과 편집한 주파수·감쇠비·물성·월드 설정·선택·재생 상태는 유지한다. 상단 초기화는 장면 기본 설정으로 돌아가며 정지한다.

## 서스펜션·이동 제한 비교

**조인트 → 서스펜션·이동 제한 비교**에서 같은 크기·밀도의 바퀴 두 개를 수직 Wheel Joint에 연결한다. 초기 축 변위 0m·주파수 0.5Hz·감쇠비 0.7은 같고, A는 이동 제한 꺼짐, B는 -0.4~0.4m 제한 켜짐으로 시작한다. 중력은 (0, -9.8)m/s²이며 모터·물체 감쇠·자동 수면을 끄고 초기 각속도 2rad/s로 자유 회전한다.

정지 → **시험 복귀 (편집값 유지)** → 재생으로 비교한다. A는 스프링이 하중을 지지하는 위치까지 처지고 B는 하한 -0.4m에서 멈춘다. 월드 중력을 (0, 9.8)로 바꾸면 하한에서 벗어나 상한 0.4m에서 멈춘다. 시험 복귀는 편집한 중력을 유지하므로 같은 방향으로 반복 시험할 수 있다. 음수 변위는 아래, 양수는 위 방향이다. 제한에 닿은 뒤에는 스프링 반력과 제한 반력이 함께 하중을 지지한다.

각 바퀴의 **이동 제한 활성화·하한·상한**을 독립적으로 편집하고 축 변위·스프링 반력·제한 반력·각속도를 확인한다. A 제한을 켜면 경계에서 멈추고 B 제한을 끄면 제한 밖의 평형 위치로 이동한다. 하한과 상한이 같으면 해당 변위를 유지하며 회전은 자유롭다. 청록 화살표는 이동축과 변위 0 기준, 초록 표시는 하한, 빨강 표시는 상한이다. 기존 인스펙터의 밀도·물성·감쇠 편집과 왼쪽 드래그도 유지한다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘·토크와 조인트의 누적 충격량을 해제하고 초기 위치·회전·선속도 0·각속도 2rad/s를 복원한다. 물체·조인트 handle과 편집한 제한·물성·월드 설정·선택·재생 상태는 유지한다. 상단 초기화는 장면 기본 설정과 아래 방향 중력으로 돌아가며 정지한다.

## 서스펜션·회전 모터 비교

**조인트 → 서스펜션·회전 모터 비교**에서 같은 크기·밀도의 바퀴 두 개를 수직 Wheel Joint에 연결한다. 스프링 주파수 1Hz·감쇠비 0.7과 초기 축 변위 0m·각속도 0은 같고, A는 회전 모터 꺼짐, B는 켜짐으로 시작한다. 목표 각속도 4rad/s·토크 한도 0.05N·m이며 중력 (0, -9.8)m/s²를 적용한다. 이동 제한·물체 감쇠·자동 수면은 끈다.

정지 → **시험 복귀 (편집값 유지)** → 재생으로 비교한다. A는 회전하지 않고 B는 목표 각속도로 가속하지만 두 바퀴의 기본 처짐 궤적은 같다. 회전 모터는 수직 스프링 운동을 고정하지 않는다. 음수 목표는 감속 후 반대 방향으로 회전하고, 활성 모터의 목표 0은 토크 한도 안에서 제동한다. 모터를 끄거나 토크 한도를 0으로 바꾸면 이미 회전 중인 바퀴는 감쇠 없이 계속 회전한다.

각 바퀴의 **모터 활성화·목표 각속도·토크 한도**를 독립적으로 편집하고 축 변위·각속도·실제 모터 토크를 확인한다. A 모터를 켜면 B처럼 회전하고, B 목표를 -2rad/s로 바꾸면 반대 방향으로 추종한다. 토크 한도를 0.001N·m로 낮추면 가속이 느려진다. 기존 인스펙터의 밀도·물성·감쇠 편집과 왼쪽 드래그도 유지한다. 같은 주파수에서 밀도만 바꾸면 스프링의 평형 처짐은 유지되지만 회전 관성이 바뀌므로 같은 토크의 각가속도는 달라진다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘·토크와 조인트의 누적 충격량을 해제하고 초기 위치·회전·선속도·각속도 0을 복원한다. 물체·조인트 handle과 편집한 모터 설정·물성·월드 설정·선택·재생 상태는 유지한다. 상단 초기화는 장면 기본 설정으로 돌아가며 정지한다.

## 웰드·선형/회전 탄성 비교

**조인트 → 웰드·선형/회전 탄성 비교**에서 같은 크기·밀도의 막대 세 개를 한쪽 끝에서 고정 지지한다. 막대의 반크기는 (0.5, 0.1)m이며 초기 위치·회전·속도에서 중력 (0, -9.8)m/s²를 적용한다. A는 선형·회전 모두 0Hz의 강체 연결, B는 선형만 1Hz, C는 회전만 1Hz로 시작한다. 두 방향의 감쇠비는 모두 0.7이고 물체 감쇠·자동 수면은 끈다.

정지 → **시험 복귀 (편집값 유지)** → 재생으로 비교한다. A는 연결점과 자세를 유지하고, B는 수평 자세를 유지하며 연결점이 아래로 처진다. C는 연결점을 유지하면서 막대가 아래로 기울어진다. 청록 점은 고정점, 보라색 점은 막대의 연결점이며 두 점 사이의 선은 선형 오차를 보여준다.

각 막대의 **선형·회전 주파수**를 독립적으로 편집하고 연결점 오차·기준각 0에 대한 상대 각도를 확인한다. 웰드의 0Hz는 해당 방향의 강한 제약이며 스프링 힘을 제거하는 뜻이 아니다. A 선형 주파수를 1Hz로 바꾸면 B와 같은 처짐을 보이고, C 회전 주파수를 0으로 바꾸면 다시 자세를 유지한다. 기존 인스펙터의 밀도·물성·감쇠 편집과 왼쪽 드래그도 유지한다.

**시험 복귀 (편집값 유지)**는 드래그·유지 입력·누적 힘·토크와 조인트의 누적 충격량을 해제하고 초기 위치·회전·선속도·각속도 0을 복원한다. 물체·조인트 handle과 편집한 선형·회전 주파수·물성·월드 설정·선택·재생 상태는 유지한다. 상단 초기화는 장면 기본 설정으로 돌아가며 정지한다.

## ShapeCast 시각화

공간 조회 카테고리에서 **ShapeCast 이동 충돌 시각화**를 고르면 시작 위치·전체 도착점·최초 충돌 시 도형·충돌점·법선·미리보기 진행 위치를 비교할 수 있다. 왼쪽 클릭으로 도착점을 바꾸고 Inspector에서 원·캡슐·상자 및 Sensor 포함을 선택한다. 재생은 미리보기만 전진하므로 실제 Body는 움직이지 않는다. 상세 범위는 [전용 문서](../docs/sandbox-shape-cast-visualization.md)를 따른다.

동일한 경로에 대해 RayCast 중심선과 ShapeCast 이동 도형의 충돌 시점을 비교하거나 이동 AABB 후보 수를 관찰할 수 있다. Shift+왼쪽 클릭은 도형의 시작점을 옮기며, 화면 표시 토글은 조회 결과에 영향을 주지 않는다.

## AABB 후보와 정확한 도형 겹침 비교

공간 조회의 **AABB·실제 도형 겹침 비교** 장면은 같은 원·캡슐·상자 조회 도형에 대해 `overlapAABB` 후보와 `overlapShape` 확정 결과를 비교한다. 초기 위치에서는 AABB만 겹치는 반례를 보여주며 클릭으로 조회 도형을 이동하면 구분을 확인할 수 있다. 자세한 내용은 [전용 문서](../docs/sandbox-overlap-shape-visualization.md)에 정리했다.


## Contact Begin / End / Hit 시각화

강체·조인트 데모의 **디버그 표시 → 접촉 이벤트**를 켜면 현재 장면의 일반 Shape에 Contact Begin/End 및 Hit 구독을 활성화한다. 기본값은 꺼짐이며 Sensor Shape는 구독하지 않는다. 이벤트 표시를 끄면 해당 데모 Shape의 구독도 해제된다.

- 녹색 **시작**, 주황색 **종료**는 이벤트 발생 당시 두 Shape의 AABB 중심 사이에 남긴 pair 표시이다. 실제 접점 좌표가 아니며 Shape가 파괴된 경우 위치를 그리지 않고 이벤트 개수에만 반영한다.
- 빨간색 **충격**은 Solver가 제공한 world 접점 및 A→B 법선이고 접근 속도(m/s), 법선 임펄스(N·s)를 함께 표시한다. **충격 최소 접근 속도**로 Hit 임계값을 바꿀 수 있다.
- Sandbox는 이벤트가 발생한 물리 Step 직후 위치를 별도 snapshot으로 복사하고 기본 0.35초 동안 흔적을 유지한다. 다음 Step에서도 남아 있다가 물리 시간이 흐르면서 사라지고, 표시가 옅어진다. 오래된 기록부터 지우며 최대 256개를 보관한다. 유지 시간은 0.05~2.0초로 조절할 수 있고 `이벤트 흔적 지우기`로 즉시 초기화한다.
- 일시 정지나 `Step(0)`에서는 물리 시간이 흐르지 않아 흔적이 줄어들지 않는다. 데모의 시험 복귀 또는 이벤트 표시 해제 시 흔적은 지워진다. **최근 Step의 이벤트 개수**는 기록된 흔적 개수와 다르다. 빠른 CCD-only TOI는 Hit 기록에 포함되지 않을 수 있다.

엔진 API와 이벤트 수명 규칙은 [Contact Begin/End](../docs/world-contact-events.md) 및 [Contact Hit](../docs/world-contact-hit-events.md)를 참고한다.
