# 모터 자동차: 바퀴 제약과 접촉의 조합

2026-10-07, master `5602c89`의 Wheel 스프링·이동 제한·모터를 차체와 두 바퀴에 연결했다. 개별 제약을 이해한 뒤 같은 Sandbox에서 연결 장치의 하중·마찰·주행을 관찰하는 학습 데모다. 물리 solver나 범용 차량 계층은 추가하지 않았다.

## 장면과 물리적 의미

**연결 장치 / 모터 자동차**는 동적 직사각형 차체와 반지름 0.35 m의 원형 바퀴 두 개, 정적 평지와 낮은 경사면으로 구성한다. 차체 Shape 밀도는 2, 바퀴 밀도는 1이다. 바퀴·바닥·경사면의 마찰 계수는 0.9로 시작하며 Inspector에서 바꿔 비교한다. 바닥은 x=-25~25 m이고 경사면 끝은 낮은 단차이므로 내려오며 서스펜션과 착지를 관찰한다.

두 Wheel Joint의 A는 차체, B는 각각의 바퀴다. 차체 기준 연결점은 x=±0.9 m, y=-0.45 m이며 로컬 위쪽 축을 따른다. 축과 경계도 차체와 함께 회전한다. 스프링은 4 Hz/감쇠 0.7, 이동 제한은 on/-0.25~0.25 m다. 연결된 차체-바퀴의 충돌은 Joint가 제외하며 바퀴-바닥 접촉은 유지한다. 기본 모터는 꺼져 있어 먼저 중력 아래 하중과 평형을 관찰한다.

바퀴를 시계 방향으로 돌리면 바닥 마찰이 차체를 오른쪽으로 추진한다. 입력을 차체의 수평 힘이나 위치 변화로 치환하지 않는다. 두 바퀴가 각각 토크 한도를 가지며 차체에는 모터의 반작용도 적용된다. 자세한 수학과 좌표계는 [기본 Wheel](wheel-joint.md), [이동 제한](wheel-limit.md), [회전 모터](wheel-motor.md)를 따른다.

## 조작과 접힌 설정

- 캔버스 위 **A/D 유지**: 왼쪽/오른쪽 주행. 양쪽을 동시에 누르면 모터를 끈다.
- **스페이스 유지**: 목표 상대 각속도 0의 제동. 주행보다 우선한다. 기존 강체 데모의 점프 입력을 자동차에는 적용하지 않는다.
- 키를 놓으면 **자유 주행**한다. 모터를 끄지만 이미 가진 물리 속도를 지우지 않는다.
- 왼쪽 드래그로 차체나 바퀴를 잡고 오른쪽 클릭으로 차체를 커서 방향으로 밀어본다. 가운데 드래그로 경로를 따라가며 Reset으로 시작 위치·설정을 복원한다.

‘구동 모터 설정’은 기본 접혀 있다. 편집용 속도 크기 8 rad/s, 바퀴당 최대 구동·제동 토크 5 N·m로 시작한다. UI에서 각각 0~20 rad/s, 0~20 N·m를 조절한다. 속도는 부호 없는 크기이고 실제 방향은 A/D가 결정한다. 토크 0은 주행과 제동의 힘을 모두 끈다. 속도 0과 토크 0의 차이를 비교한다.

‘서스펜션 설정’도 기본 접혀 있다. 양쪽 스프링·이동 제한을 함께 조절하며 UI 범위는 0~10 Hz, 감쇠 0~2, 변위 -0.5~0.5 m다. 직접 숫자 입력도 범위와 lower<=upper를 지킨다. ‘바퀴 반력 관찰’을 펼치면 각각의 상대 각속도·모터 토크·축 변위·스프링 힘·제한 힘을 확인한다. 기본 화면은 차체 수평 속도와 짧은 조작 안내를 보여준다. 청록색 축, 초록/빨강 이동 경계, 보라색 바퀴 방향은 기존 Wheel 표시를 재사용한다.

## 비교할 실험

먼저 Play에서 하중 평형을 관찰하고 D로 평지를 주행한다. 모터 토크를 낮추면 가속과 경사면 주행이 달라진다. 바퀴 또는 바닥 마찰을 낮추면 바퀴가 회전해도 차체가 충분히 추진되지 않을 수 있다. 속도×바퀴 반지름은 미끄러지지 않는 경우의 대략적인 주행 속도이며 실제 수평 속도와 항상 같지는 않다.

스프링 주파수·감쇠를 바꾸며 경사면 진입/착지의 변위와 반력을 비교한다. 스프링을 꺼도 이동 경계가 지지할 수 있지만 스프링과 제한을 모두 끄면 하중을 지지하지 못한다. A로 역방향 주행하고 스페이스로 제동한 뒤 키를 놓아 모터 off와 제동의 차이를 확인한다. UI 편집·포커스 상실·캔버스 이탈·카메라 이동·Pause는 주행과 제동 입력 및 Mouse Joint를 취소하며 Wheel Joint와 물리 속도는 유지한다.

## 검증과 다음 학습

NDEBUG 독립 `sandboxDemoTests`에 장면/Joint 구성·초기 설정·실제 주행/역회전/제동·제동 우선순위·양쪽 키·토크 0·입력 취소/활성 설정 변경·Mouse/Reset/Pause·substep 1/4의 경사면 주행/착지를 추가했다. Windows Sandbox 구성은 같은 target에서 실제 ImGui headless 전환·drawing·접기·양쪽 스프링/제한 toggle·모터/스프링/변위 직접 숫자 입력을 실행한다. 작은 위치 오차가 남는 soft limit과 설정 변경 시 coupled warm cache 폐기를 고려한다.

차체 직접 힘 적용, 회전 부호 오류, 제동 우선순위 누락, 취소 시 모터 갱신 누락, 한 바퀴만 갱신하는 다섯 오류 변형을 검사에서 검출하고 원본 byte를 복구했다. CTest47개/Windows Release runtime17개를 유지하며 전체 빌드·원격 CI 결과는 작업 PR에 기록한다. 실제 OS/GPU 창 시각 확인과 기존 assert 기반 Release 공백은 별도다.
