# Compact Schur body inverse-mass reads

The coupled Cut-cell pressure solver evaluates the matrix-free Schur operator `A = L + B M_body^-1 B^T` many times per PCG solve. The existing B-transpose pass accumulates a three-component force/torque response per dynamic body, while the B pass re-reads each body's `inverseMass` and `inverseInertia` from the full `fluidShapeObstacle2` geometry variant **for every boundary face and matrix product**. These two scalar inverse masses do not change within a pressure solve.

This change adds a small `coupledBodyInverseMass` (two doubles) scratch vector populated **once per coupled solve** for dynamic-response owners. The default-ON toggle `setAnalyticCutCellCompactSchurBodyMassEnabled(bool)` makes the cut-cell analytically disjoint Schur product use this compact lookup instead of revisiting the complete obstacle representation. The reference path remains selectable when OFF; binary MAC and sampled geometry continue to use the reference path.

The Laplacian face products, pressure/body B-transpose accumulation, per-cell B application order, floating-point casts, inverse-mass multiplications, IC(0) and PCG tolerance/true-residual validation are unchanged. A body whose inverse mass or inertia changes between World steps receives a freshly populated compact response on the **next** pressure solve; there is no cross-step mass cache.

**Regression:** Extend `checkCachedSchurLaplacianDifferential` with an independent compact-ON vs obstacle-lookup-OFF comparison, while keeping identical indexed boundary and cached Schur edge modes. Test moving overlapping/disjoint/contained circles, mixed static/dynamic bodies, and a static-to-dynamic-to-static transition at 0.5m/0.25m. The compact differential requires exact PCG iteration count, relative residual, pressure residual, continuity, per-body force/torque and fluid momentum. Existing edge-cache differential tests continue unchanged.

**Performance gate:** Windows Release `fluidPreconditionerBenchmark --schur-body-mass-sweep` compares the same field/RHS and two dynamic bodies with 0/16/48 additional static circles on 0.5m and 0.25m grids, with split active IC(0) and cached Schur edges both ON. CSV reports matrix product time, preconditioner time, PCG time, whole Step time, convergence and true residual (median of five runs). Timings are informational and the new lookup should not be merged if it does not measurably improve these scenes.
