# 누적 거리 기준 닫힌 스플라인 레일

`splineRailJointDef::isLoop = true`로 생성한다. 기본값 false는 기존 열린 레일의 동작과 양 끝 정지를 유지한다. 모드는 생성 시 결정하며 새 데모나 실행 중 모드 전환 API는 추가하지 않는다.

## 거리와 제약

- 기존 닫힌 Catmull–Rom geometry와 regular curve 검증을 사용한다. 제어점은 최소 3개이며 닫는 첫 점을 마지막에 중복하지 않는다.
- 초기 누적 좌표 S는 생성 시 투영점까지의 거리다. 이후 전진은 증가, 후진은 감소하며 `currentTranslation = S - referenceDistance`이다. `length`는 한 바퀴 길이다.
- 마지막·첫 구간을 연결해 추적한다. 위치·접선 조회는 순환하지만 누적 거리에는 주회분을 보존한다. 교차점에서 전역 최근접 분기로 다시 선택하지 않는다.
- 이음새에는 끝점 정지가 없다. 사용자 리미트는 누적 이동량 구간을 제한하며 한 바퀴 범위와 교차할 필요가 없다. 같은 하한·상한은 지정 누적 좌표를 고정한다.
- 스프링 목표도 누적 이동량이다. 같은 기하 위치에 해당하더라도 다른 주회의 목표를 가장 가까운 위치로 감싸지 않는다. 모터·제동·회전 고정·접선 추종과 강한 제약/각도 스프링의 기존 의미를 유지한다.

## 편집과 상태

- 유효한 경로 편집은 현재 누적 거리·referenceDistance·목표·리미트의 수치를 보존한다. 새 곡선에 재투영한 뒤 내부 거리 보정값을 맞춘다. 길이 변화에 따라 리미트를 비율로 재설정하지 않는다.
- 물체·조인트 handle, 자세·속도·물성은 유지한다. 기존 정책대로 impulse를 비우고 연결 물체를 깨운다. 같은 geometry는 깨우지 않는다.
- 잘못된 geometry나 재투영 실패는 geometry와 누적 상태를 모두 보존하며 거절한다. 조회·solver 반복·질량 및 설정 변경은 주행 거리를 중복 누적하거나 초기화하지 않는다.
- 기존 투영 특이점·비유한 계산 실패 정책과 소프트 제약의 수치적 유연성을 유지한다.

## 검증

닫힌 전용 회귀 테스트는 하위 단계 1/4/8과 세 회전 설정에서 정·역방향 다회전, 이음새 연속성, 반복 조회·solver, 누적 거리 리미트·스프링, 교차 분기·좌표 변환, 길이 변경 편집·실패·수명 관리를 확인한다. 기존 열린 레일·직선 동등성·데모 테스트를 함께 유지한다.

## 명시적 재투영

- `world::reprojectSplineRailJoint(id)`는 생성·편집과 같은 전역 투영을 명시적으로 요청한다. 일반 step의 연결 분기 추적은 바꾸지 않는다.
- 열린 레일은 새 투영점의 거리와 기존 끝점 연장을 사용한다. 닫힌 레일은 마지막 저장된 추적 위치에 가장 가까운 주회를 선택하며 반 바퀴 동률이면 작은 누적 좌표를 고른다. 편집 위상 보정과 0점 재설정의 기준 거리는 유지한다.
- 자세·속도·물성·handle과 스프링·리미트·회전 설정은 유지한다. 저장된 추적 상태가 달라지면 impulse를 비우고 연결 물체를 깨운다. 같은 상태의 반복 호출은 캐시와 수면을 유지한다.
- 투영·수치 검증 실패는 변경 없이 거절한다. 순간이동 중 지나간 주회 수를 추정하거나 자동으로 재투영하지 않는다.

### 구간 지정 재투영

`world::reprojectSplineRailJoint(id, segmentIndex)`는 지정 구간 안에서만 후보를 선택한다. 범위 밖 구간 번호나 해당 구간의 투영 실패는 다른 구간으로 대체하지 않고 변경 없이 거절한다. 주회 선택·제어 설정 보존·캐시 초기화·깨우기·동일 상태의 무변경 정책은 전역 재투영과 같다.

구간 제한은 명시적 호출의 후보 선택에만 적용한다. 선택한 구간의 끝점이 seed가 될 수 있으며 이후 조회와 step은 기존 연결 구간 추적으로 이어진다. 열린 레일의 물리적 양 끝 연장은 유지하고, 닫힌 마지막·첫 구간의 이음새는 같은 누적 좌표로 연결한다.

### 재투영 거리 제한

`world::reprojectSplineRailJointWithinDistance(id, maxDistance)`와 `(id, segmentIndex, maxDistance)`는 앵커와 실제 곡선 투영점 사이의 월드 거리(m)가 허용값 이하일 때만 상태를 반영한다. 열린 끝점 밖에서는 접선 방향 이격도 포함한 유클리드 거리를 사용한다. 기존 거리 제한 없는 두 호출은 유지한다.

허용값은 유한한 비음수이며 0은 평가된 투영점과 정확히 같은 앵커만 허용한다. 거리 초과·잘못된 허용값·구간·투영 실패는 캐시나 수면을 포함해 변경 없이 거절한다. 동일한 추적 상태도 거리 검사를 먼저 통과해야 하며, 성공 후의 주회·설정·물리 상태 보존 정책은 기존 재투영과 같다.

## 회전 기준 재설정

`world::rebaseSplineRailJointRotation(id)`는 현재 자세를 선택한 회전 모드의 기준으로 삼는다. 고정 모드는 B의 A에 대한 상대 각도를, 접선 추종 모드는 현재 로컬 접선과 상대 각도의 차이를 저장한다. 회전 모드와 강한 제약·각도 스프링 선택 및 튜닝은 유지한다.

자세·속도·물성·handle, 누적 거리·주회·선형 0점·추적 분기와 이동 스프링·리미트·모터 설정은 바꾸지 않는다. 기준이 달라지면 기존 결합 impulse와 반력을 비우고 연결 물체를 깨운다. 저장할 기준이 정확히 같으면 캐시와 수면을 유지한다. 저장된 추적 상태나 현재 투영이 유효하지 않으면 변경 없이 거절한다.

## 회전 기준 각도 지정

`world::setSplineRailJointRotationReference(id, angle)`는 현재 모드의 기준만 지정한다. 고정 모드에서는 A에 대한 상대 각도, 접선 추종 모드에서는 A 로컬 접선에 대한 각도 차이이며 단위는 rad이다. `splineRailJointData::tangentOffset`으로 접선 기준값을 조회한다. 선택되지 않은 모드의 기준은 유지한다.

유한한 입력값은 그대로 저장하고 회전 오차에는 기존 각도 순환 계산을 사용한다. NaN·무한대는 변경 없이 false를 반환한다. 이 설정은 재투영하거나 추적 상태를 복구하지 않는다. 자세·속도·물성·누적 거리·분기·제어 설정을 유지하며, 기준 변경 시 기존 결합 캐시를 비우고 연결 물체를 깨운다. 같은 저장값은 true를 반환하며 캐시·수면을 유지한다. 생성 및 접선 모드 진입 시 현재 자세를 기준으로 잡는 기존 정책과 현재 자세 재설정 API는 유지한다.

## 회전 오차 변화 속도 조회

`splineRailJointData::currentAngularSpeed`는 회전 오차의 순간 변화율(rad/s)이다. 고정 모드는 B와 A의 상대 각속도이며, 접선 추종은 이동하는 곡선의 접선 회전까지 반영한다. 기존 solver의 회전 row와 같은 곡률·앵커·질량중심·횡방향 투영 보정을 사용하고 열린 끝점 밖의 접선 연장 정책을 유지한다.

회전 오차 표시가 ±π에서 접히는 2π 차이를 속도로 해석하지 않는다. 강한 제약·각도 스프링 선택이나 일정한 기준 각도·선형 0점은 이 순간 변화율의 정의를 바꾸지 않는다. `trackingValid`가 false이면 기존 이동 속도 조회처럼 0을 반환한다. 조회는 분기·누적 거리·기준·물체 자세·속도·캐시·수면 상태를 변경하지 않는다.

## 회전 구속 해제·재활성화

생성·조회 데이터의 `enableRotation` 기본값 true는 기존 고정·접선 추종 동작을 유지한다. `world::setSplineRailJointRotationEnabled(id, enabled)`로 각도 복원 제약만 켜고 끈다. false에서는 normal row만 풀고 이전 각도 impulse는 warm start에서 사용하지 않는다. 앵커의 곡선 안내와 이동 스프링·모터·리미트·열린 끝점 정지는 유지한다. 비중심 앵커의 반력은 계속 물체를 회전시킬 수 있으므로 전체 반력 토크를 0으로 만들지 않는다.

모드·두 기준 각도·각도 스프링 설정과 이동 제어 설정을 보관하며, 다시 켜면 저장된 기준으로 제어를 재개한다. 켜는 순간 현재 자세를 새 기준으로 잡지는 않는다. 필요하면 기존 현재 자세 재설정 API를 사용한다. 해제 중에도 기준·모드·튜닝·geometry 편집과 각도·각도 변화율 조회는 기존 의미를 유지한다. 다른 설정 변경이 회전 구속을 자동으로 켜지 않는다.

실제 flag 변경은 기존 결합 캐시·반력을 비우고 연결된 비정적 물체를 깨운다. 같은 값은 캐시와 수면을 유지한다. 물체 자세·속도·물성·handle 및 누적 거리·주회·선형 0점·분기는 바꾸지 않는다.

## 기존 레일 인스펙터의 회전 제어

기존 스플라인 레일 화면에서 회전 구속을 켜고 끄며, 선택한 모드의 기준 상대각도 또는 접선 기준각도를 rad 단위로 편집한다. 해제 중에도 모드·기준·스프링 튜닝을 편집할 수 있고 다시 켜면 저장된 설정을 적용한다. 모드 전환 후에는 새로 잡힌 기준값을 조회해 표시한다.

현재 자세를 기준으로 삼는 버튼은 추적이 유효할 때 사용할 수 있다. 회전 오차(rad)와 오차 변화 속도(rad/s)는 설정 적용 후의 현재 조회값을 표시한다. 회전 설정은 스플라인 제어점 Undo/Redo 기록에 넣지 않으며, 오브젝트·제어점 선택, 재생 상태와 물체 자세·속도·handle을 유지한다. 화면을 그리기만 해서는 기존 기준값을 반올림·정규화하거나 물체를 깨우지 않는다.

## 기존 레일 인스펙터의 이동 기준

현재 위치를 0점으로 버튼은 기존 `rebaseSplineRailJoint` API를 호출한다. 목표와 상하한도 함께 새 기준으로 옮겨 실제 목표·정지 위치를 유지한다. 같은 frame에서 이동 거리와 이후 목표·제한 슬라이더 범위를 새 조회값으로 표시한다. 실제 이동 속도(m/s)는 모터 목표와 별도로 `currentSpeed`를 표시한다.

재설정은 물체 자세·속도·캐시·수면·회전 설정과 선택·재생·스플라인 편집 기록을 유지한다. 추적이 유효하지 않으면 버튼을 사용할 수 없고, 수치 검증으로 거절되면 기존 좌표와 표시값을 유지한다. UI가 값을 직접 0으로 만들거나 실패한 결과를 미리 반영하지 않는다.

## 기존 레일 인스펙터의 명시적 재투영

재투영 허용 거리의 초기값은 0.5m이며 월드 거리로 편집한다. 레일에 재투영 버튼은 기존 `reprojectSplineRailJointWithinDistance`의 전체 곡선 조회를 호출한다. 추적 실패 중에도 요청할 수 있으며, 허용 거리 이하인 후보만 반영한다. 음수·비유한 허용값과 투영 실패는 변경 없이 거절한다. 물체 자세·속도를 옮기는 기능이 아니며 교차점에서는 기존 API의 전역 최근접 분기를 선택한다.

최근 재투영 표시는 마지막 버튼 요청의 성공·거절 결과다. 화면 표시나 거리 편집으로 자동 재시도하지 않는다. 성공 후 같은 프레임에서 현재 거리·속도·회전 정보를 다시 조회하며 이동 0점·목표·리미트·회전 설정은 유지한다. 실제 추적 변경만 캐시를 비우고 깨우며, 같은 상태의 성공과 실패는 캐시·수면을 유지한다. 선택·재생·스플라인 Undo/Redo 기록은 바꾸지 않는다. 새 데모 화면을 만들면 허용 거리와 최근 결과도 초기화한다.

### 인스펙터의 재투영 구간 선택

재투영 대상은 전체 곡선이 기본이며 지정 구간 모드에서는 현재 레일 geometry의 구간 목록을 고른다. 화면 번호는 1부터 시작하며 같은 허용 거리와 버튼으로 해당 구간 지정 API를 호출한다. 후보가 거리 제한을 벗어나면 다른 구간으로 대체하지 않고 거절한다. 구간 제한은 이번 재투영 후보 선택에만 적용하며 이후 주행은 기존 연결 구간 추적을 유지한다.

구간 번호는 현재 제어점 순서의 번호이며 편집 전후의 동일 곡선 부분을 식별하는 ID는 아니다. 편집으로 번호가 범위를 벗어나면 구간 재선택을 표시하고 지정 모드의 버튼을 비활성화한다. 자동으로 번호를 줄이거나 전체 곡선 모드로 바꾸지 않는다. Undo로 해당 번호가 복구되면 다시 사용할 수 있고, 전체 곡선 모드는 이전 구간 번호의 유효성과 관계없이 사용할 수 있다. 모드·목록 조작은 재투영·깨우기·편집 기록 변경을 하지 않으며 마지막 명시적 요청 결과를 유지한다. 새 화면에서는 전체 곡선 모드로 초기화한다.

### 선택한 재투영 구간 강조

지정 구간 모드의 유효한 선택은 현재 레일 geometry에서 해당 구간만 1cm adaptive sampling으로 그린다. 밝은 굵은 선과 양 끝점, 1부터 시작하는 구간 번호를 표시하며 bodyA의 현재 좌표 변환을 적용한다. 기존 경로 이동과 기본 레일 표시는 유지한다.

전체 곡선 모드·무효 구간 번호·샘플링 실패에서는 강조 전체를 숨긴다. 저장된 추적이 실패해도 geometry와 선택이 유효하면 복구할 구간을 표시할 수 있다. 강조용 geometry를 보관하지 않아 제어점 드래그·삭제·Undo/Redo의 현재 결과를 반영한다. 그리기는 재투영·깨우기·step·제어 설정 또는 편집 기록 변경을 하지 않는다.

### Alt+클릭으로 재투영 구간 선택

스플라인 레일 화면에서 Alt+왼쪽 클릭이 실제 곡선의 화면상 10px 이내이면 지정 구간 모드로 전환하고 현재 geometry의 해당 구간을 선택한다. 줌과 레일의 좌표 변환을 반영하며 기존 최근접점 조회의 동률 정책을 사용한다. 목록과 강조 표시는 즉시 같은 선택을 사용하고 재투영 자체는 기존 버튼으로 요청한다. 거리 초과·잘못된 화면 배율·조회 실패는 모드·구간과 마지막 재투영 결과를 유지한다.

Ctrl 조합은 기존 제어점 삽입을 우선한다. Alt로 시작한 왼쪽 클릭은 버튼을 놓을 때까지 선택용 입력으로 유지하며, 누른 채 Alt를 놓거나 Ctrl을 눌러도 드래그·삽입으로 바꾸지 않는다. 기존 드래그 중 Alt를 누르는 경우에도 원래 드래그를 유지한다. 포커스 차단·재생 상태 전환은 선택 입력 동작을 취소한다. 다른 데모와 키보드·오른쪽 클릭 입력의 기존 처리는 유지한다. 구간 선택은 재투영·깨우기·step·물체/제어점 변경이나 Undo/Redo 기록 추가를 하지 않는다.
