# 누적 거리 기준 닫힌 스플라인 레일

`splineRailJointDef::isLoop = true`로 생성한다. 기본값 false는 기존 열린 레일의 동작과 양 끝 정지를 유지한다. 모드는 생성 시 결정하며 새 데모나 실행 중 모드 전환 API는 추가하지 않는다.

## 거리와 제약

- 기존 닫힌 Catmull–Rom geometry와 regular curve 검증을 사용한다. 제어점은 최소 3개이며 닫는 첫 점을 마지막에 중복하지 않는다.
- 초기 누적 좌표 S는 생성 시 투영점까지의 거리다. 이후 전진은 증가, 후진은 감소하며 `currentTranslation = S - referenceDistance`이다. `length`는 한 바퀴 길이다.
- 마지막·첫 구간을 연결해 추적한다. 위치·접선 조회는 순환하지만 누적 거리에는 주회분을 보존한다. 교차점에서 전역 최근접 분기로 다시 선택하지 않는다.
- 이음새에는 끝점 정지가 없다. 사용자 리미트는 누적 이동량 구간을 제한하며 한 바퀴 범위와 교차할 필요가 없다. 같은 하한·상한은 지정 누적 좌표를 고정한다.
- 스프링 목표도 누적 이동량이다. 같은 기하 위치에 해당하더라도 다른 주회의 목표를 가장 가까운 위치로 감싸지 않는다. 모터·제동·회전 고정·접선 추종과 강한 제약/각도 스프링의 기존 의미를 유지한다.

## 편집과 상태

- 유효한 경로 편집은 현재 누적 거리·referenceDistance·목표·리미트의 수치를 보존한다. 새 곡선에 재투영한 뒤 내부 거리 보정값을 맞춘다. 길이 변화에 따라 리미트를 비율로 재설정하지 않는다.
- 물체·조인트 handle, 자세·속도·물성은 유지한다. 기존 정책대로 impulse를 비우고 연결 물체를 깨운다. 같은 geometry는 깨우지 않는다.
- 잘못된 geometry나 재투영 실패는 geometry와 누적 상태를 모두 보존하며 거절한다. 조회·solver 반복·질량 및 설정 변경은 주행 거리를 중복 누적하거나 초기화하지 않는다.
- 기존 투영 특이점·비유한 계산 실패 정책과 소프트 제약의 수치적 유연성을 유지한다.

## 검증

닫힌 전용 회귀 테스트는 하위 단계 1/4/8과 세 회전 설정에서 정·역방향 다회전, 이음새 연속성, 반복 조회·solver, 누적 거리 리미트·스프링, 교차 분기·좌표 변환, 길이 변경 편집·실패·수명 관리를 확인한다. 기존 열린 레일·직선 동등성·데모 테스트를 함께 유지한다.

## 명시적 재투영

- `world::reprojectSplineRailJoint(id)`는 생성·편집과 같은 전역 투영을 명시적으로 요청한다. 일반 step의 연결 분기 추적은 바꾸지 않는다.
- 열린 레일은 새 투영점의 거리와 기존 끝점 연장을 사용한다. 닫힌 레일은 마지막 저장된 추적 위치에 가장 가까운 주회를 선택하며 반 바퀴 동률이면 작은 누적 좌표를 고른다. 편집 위상 보정과 0점 재설정의 기준 거리는 유지한다.
- 자세·속도·물성·handle과 스프링·리미트·회전 설정은 유지한다. 저장된 추적 상태가 달라지면 impulse를 비우고 연결 물체를 깨운다. 같은 상태의 반복 호출은 캐시와 수면을 유지한다.
- 투영·수치 검증 실패는 변경 없이 거절한다. 순간이동 중 지나간 주회 수를 추정하거나 자동으로 재투영하지 않는다.
