# Movable-only analytic Schur boundary assembly

The analytic coupled-pressure operator is `A = L + B M_body^-1 B^T`. Its body Schur term receives a contribution only from bodies with nonzero inverse mass or inverse inertia. PR #296 already stopped **storing** static-body boundary faces in the matrix-free operator, but until now the analytic assembly still **clipped** each selected MAC face against every disjoint static shape.

When `setAnalyticCutCellMovableSchurFacesEnabled(true)` (default), the coupled-pressure assembly for **three or more disjoint analytic shapes** visits only movable body indices and clips their analytic geometries against the previously selected MAC faces. This reuses the movable index list needed later for each PCG matrix product. Static boundaries retain their effect on geometry, fluid-solid flux, pressure field, and independent surface-force feedback; only the massless term in the Schur body response is omitted. The output `B M_body^-1 B^T` and iteration parameters remain unchanged.

The existing full-shape scan remains selectable with `setAnalyticCutCellMovableSchurFacesEnabled(false)`. The two-circle overlap/containment geometry path always uses its original ownership-aware clipping routine, so its special-case semantics are unchanged. Owner order is preserved because the movable list is built in input order, and U/V faces are visited in original row-major order. The selection flag persists through `clear()`.

A differential regression exercises 16/48 separated immovable circles plus two moving dynamic circles on 0.5m and 0.25m grids, comparing full vs movable-only pressure convergence, iterations, residual, per-body force/torque and momentum across successive steps. Paired `fluidPreconditionerBenchmark --mobility-sweep` rows report Schur assembly time, total pressure/Field step time and convergence for 0, 16, 48 static obstacles on a common Windows Release runner. CI records timings as **informational** rather than requiring any particular speedup.
