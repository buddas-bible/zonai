# Sparse output for AABB-bounded analytic swept face flux

The AABB-bounded moving-only swept integration introduced in PR #306 clips only the MAC faces near moving shapes. Its final stage, however, still zeroed dense U/V double-precision face buffers and visited **every interior face on every intermediate time sample** before applying the result. For a large grid with a few small moving obstacles, most of these faces never receive an analytic interval.

The new default-ON `setAnalyticCutCellSparseSweptFacesEnabled(bool)` uses a touched-face list in the existing AABB-bounded path. A face is appended only on its **first strictly positive clipped interval** during the current intermediate sample. Per-face flux is still accumulated in double precision in the original moving owner order, preserving input-specific rounding and per-face summation semantics. After processing all owners, touched U indices and touched V indices are sorted into their original row-major order; each double is cast to float **once**, then added to the same swept field using the existing `intervalDt`. Finally each touched accumulator/mark is reset to zero, and both touched lists are cleared for the next sample.

Local scratch arrays and marks are allocated lazily on first use and are reused for every intermediate sample and any opt-in adaptive time-refinement pass within that Fluid Step. The sparse path does **not** persist scratch across independent Steps and never reuses current-step analytic geometry for earlier/later poses. `clear()` retains the toggle but discards normal field history as before.

When the toggle is OFF, the full-grid double `assign` and row-major output loops from PR #306 remain available as a reference. The optimization is not invoked for the two-circle overlap/containment ownership path, the sampled fallback, stationary swept paths, or when moving-only/AABB-bounded analytic flags are disabled. No equations, sampling times, body motion classification, pressure tolerances or collision semantics change.

**Validation:** moving circles (dynamic and kinematic) plus 16/48 stationary circles at 0.5m and 0.25m, and moving/rotating convex polygons and capsules, each run sparse ON vs dense OFF. The differential suite checks exact swept flux diagnostic totals, sample/refinement counts, predicted continuity, pressure convergence, per-body traction and fluid momentum. An adaptive temporal-sampling case verifies scratch reset and sorted output across refined time samples. A targeted three-circle regression additionally places two separate moving circles on distinct segments of **the same internal U face**, verifying duplicate touched-index elimination and original owner contribution order when their fluxes are combined.

**Benchmark:** `fluidPreconditionerBenchmark --swept-sparse-sweep` runs a genuine moving second Step at 0/16/48 statics, comparing dense vs sparse *while both moving-only and bounded-AABB paths are enabled*. It reports swept-phase median, whole-step median, swept sample count, flux, mismatch and convergence. Windows Release CI collects the CSV informationally; no speedup is assumed before measuring.
