The Fluid gate still reports the unchanged 14,474/1,697,236 mismatches: sampledMixed 5,979, analyticCapsule 8,495, all four other scenes exact. ## Migration

- Change only `rot2::FromRadians` in production: dispatch finite radians in the already verified interval ±float(2*pi) to `deterministicSinCosBounded`, returning the same c/s layout. Keep the original std::cos/std::sin fallback for all other inputs. No clamping, approximate large-angle modulo, or API signature changes.
- The change intentionally affects bounded rotation creation in Fluid swept interpolation and geometry fixtures, as well as World and Joint call sites. Inspected World reference-angle queries, World deltaRotation and motor joint constraint; they share this factory. Direct std::sin/std::cos outside rot2, including Sandbox wind sources, are not migrated.
- Reuse every existing bounded math fixture and require the production rot2 output to match the candidate exactly. Check local legacy behavior at 8 large finite angles (including immediately outside the supported interval and FLT_MAX) and 3 nonfinite inputs. These legacy results are not emitted as authoritative cross-platform bits.
- Retain all six Fluid trace scenes, same field names/coverage, 11,728 strict engine-math rows, and existing World/Contact/Joint strict comparisons. No changes to the actual simulation equations.
- Re-pin the existing temporary same-runner Release A/B workflow to R3k, add rot2.h to path triggers, retain swept/field timing and 192-row coupled trajectory audit. Historical results remain in R3g/R3j runs.

## Acceptance and limitations

Verify both platform trace jobs, strict fingerprints, all six scenes, full CMake, and same-runner Release A/B. Large finite angles outside the bounded interval still depend on libm: this preserves the API's numerical domain but is NOT full-range determinism. Independently validate robust argument reduction for arbitrary finite binary32 before removing the fallback. Also examine other authoritative libm paths. The sampled fixture's inputs are now generated by the same factory as the real solver, so an improved trace alone does not establish that externally provided nonidentical inputs become deterministic. If a remaining mismatch exists, locate the first differing stage and input, do not relax the gate.

No merge to master; experimental #326 unchanged. The historical A/B workflow remains a temporary audit. Full World–Fluid/Joint coupling traces, release/architecture coverage and long-run stability are separate gates.
